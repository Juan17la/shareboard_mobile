Navigation rules

One screen, many sheets

The board never unmounts while a sheet is open; the drawing stays visible behind the scrim and live updates keep arriving.

Every sheet is dismissable

Close button, tap on the scrim, Esc (web), drag down and the Android Back button (pops one level).

Board to board in place

Opening another whiteboard swaps the board id on the same screen; it does not stack a new page.

Account returns you

The account sheet remembers which sheet asked for it and goes back there after sign-in.

Gone boards let go

A deleted or forgotten board is removed from recents and the app returns to /, which opens the next one.

Same map on both clients

Web and Android have the same stations in the same places; only the toolbar position and context-menu gesture differ.
